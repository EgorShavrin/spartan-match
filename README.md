# SpartanMatch

SpartanMatch is a full-stack member-to-project matching platform designed for student organizations.

It helps match members with projects based on:

- Technical skills
- Interests
- Preferred roles
- Learning goals

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLModel
- SQLite

## Matching Algorithm

The recommendation engine uses a transparent weighted scoring system:

- Skills: 60%
- Interests: 20%
- Preferred Role: 10%
- Learning Goals: 10%
